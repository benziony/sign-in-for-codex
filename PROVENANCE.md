# Provenance

Sign In for Codex is a fresh public implementation of a behavior contract:
when Codex is blocked by a provider login or approval, hand the human step to a
private local page without putting sensitive material in chat.

The project was created with new Git history. No private repository history,
host configuration, runtime data, browser profile, authentication material, or
deployment configuration was imported.

The private production implementation that established the behavior remains a
separately owned system during an explicit compatibility window. Public code is
written, reviewed, tested, and released independently.
